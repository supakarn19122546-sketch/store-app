⚙️ ตั้งค่าการบันทึกข้อมูลด้วย GitHub

เชื่อมต่อบัญชี GitHub เพื่อบันทึกข้อมูลร้านค้าของคุณไว้บน Cloud ปลอดภัย ข้อมูลไม่หาย และซิงค์ได้ทุกอุปกรณ์
ต้องใช้ Token สิทธิ์ gist หรือ repo (คลิกที่นี่เพื่อสร้าง Token บน GitHub)
วิธีสร้าง Token ใน 1 นาที:
1. กดลิงก์สร้าง Token ด้านบน (หรือไปที่ GitHub → Settings → Developer Settings → Tokens classic)
2. ติ๊กเครื่องหมายถูกที่ช่อง gist แล้วกด Generate Token ด้านล่างสุด
3. ก๊อปปี้รหัส Token มาวางในช่องด้านบน แล้วกดปุ่ม ✨ สร้าง Gist อัตโนมัติ ได้เลย!
